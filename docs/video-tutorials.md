# Video Tutorials

These short demonstrations provide a practical guide to accessing, searching, inspecting, downloading and contributing calculations in the CCP-NC Database. You can watch the complete series in order for a full introduction, or jump straight to an individual tutorial when you need help with a specific task.

---

## Welcome and access

### Welcome to the CCP-NC Database

*Introduction, public access and ORCID login*

An introduction to the CCP-NC Database and its role as a FAIR computational NMR crystallography data resource. This tutorial explains public access, opening the CCP-NC NMR App, signing in through ORCID and confirming account information during the first login.

## Searching the database

### Finding Records by Material Name, Formula or Elements

Learn how to find CCP-NC Database records using material names, chemical formulae, specific elements and the number of constituent elements. This tutorial demonstrates the periodic table, search bar and filter menu, including equality and partial-name searches.

### Filtering by Calculation Metadata and Data Licence

Learn how to filter CCP-NC Database records using calculation and publication metadata, including the DFT program, program version, exchange-correlation functional, DOI and data licence. This tutorial also demonstrates equality search, autocomplete and combining multiple filters.

## Contributing data

Careful file preparation, descriptive metadata, dataset assignment and provenance information help make deposited calculations findable, accessible, interoperable and reusable.

### Preparing Files and Metadata for Bulk Upload

Learn how to prepare a calculation collection for bulk upload to the CCP-NC Database. This tutorial covers organising MAGRES files, creating metadata_info.csv, matching filenames and supplying metadata that makes deposited calculations findable and reusable.

### Bulk Upload, Dataset Assignment and Publication
